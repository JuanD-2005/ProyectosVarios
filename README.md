# 🏛️ Archivo Histórico Universitario (2022 - 2024)

> *"Todos empezamos en algún lugar. Este es el mío."*

Bienvenido a mi "museo" personal de código. Este repositorio es una cápsula del tiempo que contiene mis primeros proyectos, prácticas y asignaciones de la carrera universitaria (Estructura de Datos, Computación I, Programación I y II).

Aquí encontrarás código en su estado más puro y crudo: escrito desde cero, sin asistencia de IA, y lleno de la curiosidad (y frustración) de alguien que estaba descubriendo los fundamentos de la ingeniería de software. Verás nombres de variables cuestionables y lógica de fuerza bruta, pero también mucha perseverancia para hacer que las cosas compilaran. 😅

## 🗂️ ¿Qué hay en este baúl?

A través de estos archivos se puede mapear mi aprendizaje inicial. Algunos de los proyectos más destacados incluyen:

### 🌳 Estructuras de Datos y Algoritmos (C++)
*   **Grafos y Árboles (`Proyecto Arbol.cpp`, `Grafos.cpp`):** Implementaciones manuales de estructuras de datos no lineales, manejando punteros y memoria dinámica.
*   **Algoritmos Básicos (`Proyecto Ordenacion y Busqueda.cpp`):** Mis primeros acercamientos a la eficiencia y la notación Big O.
*   **Juego de Veintiuno / Blackjack (`Veintiuno - Proyecto Listas.cpp`):** Un juego funcional creado enteramente aplicando la teoría de **Listas Enlazadas**.

### 🧠 Lógica de Programación y Juegos
*   **ChessGame:** Mis primeros intentos de modelar reglas complejas y tableros en código.
*   **Sopas y Números Romanos:** Ejercicios clásicos de algoritmia y manipulación de strings/matrices.
*   **SistemaFinal.cpp:** El clásico proyecto integrador para salvar el semestre.

### 🌐 Mis Primeros Pasos Web y Backend
*   **Prácticas HTML (`Practica_Uno.html`):** Donde descubrí cómo estructurar la web antes de siquiera conocer CSS a fondo o frameworks modernos.
*   **ProblemasBackend:** Mis primeros retos de lógica orientada a servidores.
